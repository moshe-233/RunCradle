已用 view_image 检视两图的区域布局、六节点连接、文字层次、图标、表单和底部证据条。候选配色按 sRGB 相对亮度计算了正文、辅助文字、占位文字、强调文字、运行按钮和状态标签的文字对比度，当前检查值最低为 4.72:1。浅色占位文字参数从 #737C89 调整为 #6B7482，候选对比度从 4.22:1 提高至 4.72:1；这项是配色参数修订，效果图像素未重新生成。参数表示后续实现的候选值，生成图片用于整体观感验收；产品代码与浏览器验证尚未进入本轮。

配色组织参考：[Radix 的明暗色阶](https://www.radix-ui.com/themes/docs/theme/color)、[Material 的暗色表面与强调色使用](https://developer.android.com/develop/ui/compose/designsystems/material?hl=en)。本轮具体色值为 RunCradle 的设计提议。
