# RunCradle 插件入口

当用户需要确认 RunCradle 的 DSH 插件已加载，或了解当前插件能力时，使用本说明。

## 调用探针

调用 `runcradle_probe`，参数为 `{}`，也可传入 `{ "echo": "你好，RunCradle" }`。

成功时返回：

```json
{
  "plugin": "dsh-runcradle",
  "version": "0.1.0-alpha.0",
  "echo": "你好，RunCradle"
}
```

`version` 是实际安装的插件版本。省略 `echo` 时返回空字符串。探针不会启动程序、访问工作区文件或执行工作流。它仅证明插件工具调用链可用，不能用来判断 RunCradle 工作流运行时是否健康。

## 当前能力边界

当前版本仅提供插件入口、探针和本说明。工作流查找、创建、修改、校验、执行、停止、结果查询及工作区服务管理尚未提供；不要声称这些能力已实现，也不要把本说明当作执行这些操作的授权。

如果工具不可见，请检查目标 Profile 是否启用了此 Bundle，以及当前 Agent 的工具限制。参数错误、取消、插件加载失败应如实报告，不能将失败描述为验证成功。
